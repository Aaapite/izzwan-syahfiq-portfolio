## Implementation and verification

Use the existing static Vite/JavaScript application and npm lockfile. Node.js 22.12+ is required. Install with `npm ci` when dependencies are missing or changed.

- `src/content.js`: bilingual copy, project records and links.
- `src/render.js`: semantic templates and SVG icons.
- `src/main.js`: interactions and motion.
- `src/theme.js`: theme selection before first paint.
- `src/style.css`: layout and theme tokens.
- `index.html`: generated by `scripts/generate.mjs`; edit its sources.

For application changes, run `npm test` and `npm run build`. Review affected behavior in a real browser at desktop and phone sizes in both languages/themes as applicable. Record what actually passed and any limits in `docs/VALIDATION.md`, and update `docs/PROGRESS.md` and current context when behavior changes. Regenerate the offline preview with `npm run export:preview` after building.

For documentation-only changes, verify links, consistency and the Git diff; do not claim new application/browser testing. Generated `dist/`, `PREVIEW.html`, dependencies and environment files stay ignored.
